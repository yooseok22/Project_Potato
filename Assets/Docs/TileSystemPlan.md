# 배열 + 청크 메시 타일 시스템

## 현재 구성

- 적용 씬: `Assets/Scenes/YoungSeok/YoungSeok.unity`
- 타일 원본: `Assets/Fbx/Tile/v2_last/FBX_Land Tile v.2-001~014.prefab`
- 타일 구역: 원점 `(-50, 0, -50)`, 50×50칸, 한 칸 2m
- 청크 크기: 16×16칸
- 입력: 오른쪽 클릭으로 파기, 왼쪽 클릭으로 덮기

`GroundGrid`가 파기 상태를 보관하고, `GroundTileRenderer`가 선택 칸과 주변 8칸의 상태를 읽어 001~014 중 하나를 선택한다. 각 칸마다 프리팹 인스턴스를 만들지 않고 청크별 표시 메시와 `MeshCollider` 하나로 결합한다. 변경 시 선택 칸 주변에서 외형이 달라진 청크만 다시 만든다.

1안 렌더러, 4분할 메시 조합, 1안/2안 전환 컴포넌트와 F1/F2 테스트 입력은 제거했다. 현재 씬에는 최종 렌더러 하나만 사용한다.

## 최종 타일 규칙

| 프리팹 | 선택 조건 |
| --- | --- |
| 001 | 파지 않은 기본 칸 |
| 002 | 상하좌우 연결이 없는 단독 파기 |
| 003 | 상하좌우 중 한 방향 연결 |
| 004 | 서로 마주 보는 두 방향 연결 |
| 005 | 붙어 있는 두 방향과 그 사이 대각선 연결 |
| 006 | 세 방향 연결, 열린 쪽 두 대각선도 연결 |
| 007 | 붙어 있는 두 방향 연결, 그 사이 대각선은 미파기 |
| 008 | 세 방향 연결, 열린 쪽 두 대각선 중 하나는 미파기 |
| 009 | 세 방향 연결, 열린 쪽 두 대각선 모두 미파기 |
| 010 | 상하좌우와 대각선 세 방향 연결(대각선 하나 미파기) |
| 011 | 상하좌우와 대각선 두 방향 연결(대각선 둘 미파기) |
| 012 | 상하좌우와 대각선 한 방향 연결(대각선 셋 미파기) |
| 013 | 상하좌우만 연결되고 대각선은 모두 미파기 |
| 014 | 상하좌우와 네 대각선이 모두 연결된 완전 내부 칸 |

009의 실제 메시에는 한쪽 직선 벽과 반대쪽 두 모서리 돌출이 있다. 따라서 세 방향이 파여 연결되고, 남은 벽의 반대편 두 대각선이 모두 파이지 않은 경우로 해석했다.

011은 인접한 두 대각선이 미파기인 모양으로 제작되어 있다. 서로 마주 보는 두 대각선만 미파기인 경우에는 회전만으로 정확히 같은 형태를 만들 수 없으므로, 일치하는 모서리가 가장 많은 011 방향을 결정적으로 선택한다.

비대칭 모양은 회전과 X축 반전을 함께 사용한다. 반전 시 삼각형 winding도 뒤집어 컬링과 법선 방향이 유지된다.

## 관련 파일

| 파일 | 역할 |
| --- | --- |
| `Assets/Scripts/Farming/GroundGrid.cs` | 구역과 파기 상태 관리 |
| `Assets/Scripts/Farming/TileVisualResolver.cs` | 주변 8칸에서 001~014와 회전/반전 선택 |
| `Assets/Scripts/Farming/TileMeshSource.cs` | 프리팹 메시를 읽어 청크에 추가 |
| `Assets/Scripts/Farming/GroundTileRenderer.cs` | 청크 표시 메시와 충돌 메시 생성/갱신 |
| `Assets/Scripts/Farming/FarmingTargetSelector.cs` | 선택, 거리/장애물 검사, 파기/덮기 입력 |

최종 FBX는 런타임 청크 결합을 위해 `Read/Write Enabled`가 켜져 있어야 한다.
