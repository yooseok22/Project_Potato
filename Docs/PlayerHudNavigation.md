# HUD 나침반 및 도구 선택

수정일: 2026-10-25

대상 프리팹: `Assets/UI/Prefabs/PotatoHUD_Design.prefab`

연결 씬: `Assets/Scenes/Test/YoungSeok_TestScene.unity`

## 나침반

기존 `Bar_Compass` 대신 `Assets/UI/compass.png`의 눈금 아트를 사용한다. 원본에 반복된 북쪽 표기는 마스킹하고, 실제 방위 N·NE·E·SE·S·SW·W·NW 및 15도 간격 숫자를 배치한다. 원본 이미지 파일과 스프라이트 슬라이스는 수정하지 않는다.

`PlayerHudNavigation`은 로컬 플레이어 카메라의 수평 시선 방향을 읽는다. 월드 +Z를 북쪽 0도, +X를 동쪽 90도로 계산하고, 중앙 기준점과 현재 각도를 고정한 채 눈금과 방위 문자를 반대로 이동시킨다. 북쪽의 359도→0도 경계에서도 연속적으로 표시한다. 카메라를 위아래로 보는 동작은 방위에 영향을 주지 않는다.

기존 나침반의 장식/목적지 아이콘은 유지하며, 실제 퀘스트나 집 위치의 월드 좌표 연동은 이번 변경에 포함하지 않는다.

## 도구 UI

현재 선택은 중앙 큰 슬롯, 휠 위로 선택할 이전 도구는 왼쪽 작은 슬롯, 휠 아래로 선택할 다음 도구는 오른쪽 작은 슬롯에 표시한다. 선택 순서는 실제 `PlayerItemController`와 동일하다.

`맨손 → 괭이 → 물뿌리개 → 낫 → 감자 포크 → 맨손`

- 맨손: 텍스트로 표시.
- 괭이: 기존 괭이 그림인 `Icon_Tool_Scraper`.
- 물뿌리개: `Icon_Tool_Kettle`.
- 낫: `Icon_Tool_Sickle`.
- 감자 포크: `Assets/UI/basketFarming_tool.png`의 `basketFarming_tool_1`.

도구 선택 이벤트를 구독하므로 휠, 숫자 키, 코드에 의한 슬롯 선택 모두 현재·이전·다음 이름과 아이콘을 즉시 갱신한다. 도구 이름에는 프로젝트의 기존 `MalgunGothic-Dynamic` 글꼴을 사용한다. 기존 바구니와 스크롤 안내, 나머지 HUD 배치는 유지한다.

## 연결과 검증

`Tools > Project Potato > Connect HUD Compass and Tool Wheel` 메뉴는 원본 프리팹과 현재 씬 HUD에 필요한 컴포넌트와 참조를 연결하고 저장한다. 중복 생성 없이 다시 실행할 수 있다.

스크립트 컴파일과 실제 플레이 모드의 52개 검증을 통과했다. 다섯 슬롯의 세 아이콘 일치, 양방향 슬롯 순환, 카메라의 90/180/270/0도와 중앙 방위 일치, 북쪽 경계 연속성, 한글 글꼴을 확인했다. 실제 Game 화면을 캡처하여 225도 SW와 선택된 감자 포크, 이전 낫, 다음 맨손의 배치 및 글자 표시를 확인했다.
