# 바구니에서 감자를 선택해 가공하기

연결 씬: `Assets/Scenes/Test/YoungSeok_TestScene.unity`  
플레이어 프리팹: `Assets/Prefabs/Player.prefab`

## 조작

- `0` 또는 숫자패드 `0`: 테스트용으로 바구니 빈자리를 1·2·3성 및 상태이상 감자 중 무작위로 채운다. 기존 감자는 유지하고 총 10개까지만 채우며 활성 슬롯에 저장한다. 가득 차 있으면 변경하지 않는다. 바구니 선택 모드를 닫은 일반 플레이 상태에서 사용한다.
- 빈 믹서기 또는 부분 투입한 믹서기를 조준하고 `E`: 바구니를 앞으로 꺼내 선택 모드에 들어간다. 손에 운반 물건이 있으면 먼저 내려놓아야 한다.
- 바구니 위 감자에 커서를 올리면 등급 또는 복수 상태이상 정보를 표시한다.
- 좌클릭: 상태이상이 없는 1~3성 감자 1개를 투입한다. 남은 표시 감자는 유지하며 빈 슬롯은 자동 보충하지 않는다.
- 상태이상 감자는 콘솔에 `상태이상 감자는 넣을 수 없습니다.`를 출력하고 소비하지 않는다. 무등급 일반 감자도 거부한다.
- `R`: 0.45초 동안 바구니를 흔든 후 최대 3개를 다시 표시한다. 흔들리는 동안 클릭과 추가 리롤을 차단한다.
- `Esc`: 바구니를 등에 돌려놓는다. 이미 투입한 감자와 현재 표시 목록은 유지하므로 다시 `E`로 이어서 선택할 수 있다.
- 기본 4개를 채우면 자동으로 선택 모드를 닫고 믹서기 뚜껑을 닫는다. 이후 믹서기에 `E`로 기존 분쇄·운반·붓기 공정을 진행한다.
- 선택 중 이동, 시점 회전, 도구 사용과 일반 상호작용을 차단한다. 종료 클릭이 도구 사용으로 이어지지 않게 소비한다.

## 추첨 규칙

감자 개수만큼 개별 런타임 식별값을 부여한다. 같은 등급·상태라도 서로 다른 감자이며 종류별 균등 추첨이 아닌 개체별 균등 추첨이다. 상태이상 감자도 추첨 후보에 포함한다.

직전 표시 목록을 제외하고 새 후보를 먼저 무작위로 뽑는다. 새 후보가 3개 미만이면 부족한 자리만 직전 목록에서 채운다. 따라서 4~5개 보유 시에도 3개가 표시되며, 3개 이하이면 보유한 감자가 전부 표시된다. 이번에 표시되지 않은 감자는 다음 리롤부터 다시 후보가 된다. 표시용 개체 식별값과 리롤 기록은 플레이 세션 내에서만 유지하며 저장 파일을 불러오면 선택을 종료하고 새 인벤토리를 기준으로 구성한다.

## 실제 차감과 저장

`PotatoProcessingService.TryInsert`가 정상 감자 여부와 설비 수용 상태를 검사하고 바구니에서 정확히 1개를 제거한다. 바구니와 설비를 기존 활성 슬롯에 한 번 저장한다. 실패하거나 예외가 발생하면 원래 감자의 식별값·순서·수량과 설비 투입량을 복구한다. 수량이 0이 된 스택은 저장 목록에서도 제거한다.

설비는 기존 `IInventorySaveTarget` 계약에 `processor:<영구 ID>` 소유자로 연결한다. 별도의 필수 저장 섹션이나 기존 감자 저장 형식 변경 없이 투입량, 공정 단계, 남은 시간과 생산 수량을 저장한다. 원래 저장 파일에 설비 기록이 없으면 빈 설비로 복원한다. 설비 상태가 바뀔 때도 자동 저장한다.

들고 있던 믹서기는 재개 가능한 원위치로 돌아가고, 운반 중이던 젖은 틀은 다시 집을 수 있는 아래 위치로 복원한다. 건조 중 또는 포장 대기인 틀은 상단과 남은 시간·전분량을 복원한다. 손에 든 물건의 런타임 참조는 저장하지 않는다. 기존 포장지·완성 팩 플레이어 인벤토리의 영구 저장은 기존 범위와 동일하다. 현재 로컬 저장 시스템에 맞춰 오프라인에서 동작한다.

## 프로토타입 프랍

`BasketProcessingView`가 나무 슬랫·테두리·등 끈을 기본 도형으로 만들고, 감자를 구형 메시와 눈·싹으로 표시한다. 바구니는 평소 플레이어 등에 있으며 선택 시 카메라 앞으로 이동한다. 설명과 조작 안내는 기존 한글 폰트를 사용하는 uGUI다. 별도 그림·모델 파일이 필요 없다.

## 연결과 검증

- `Tools > Project Potato > Connect Processing Basket`: 플레이어 프리팹과 씬 플레이어에 선택 컨트롤러를 추가하고 설비에 영구 저장 ID를 부여한다.
- `Tools > Project Potato > Validate Processing Basket`: 0~10개 추첨, 직전 제외·부족분 보충·재등장, 실제 감자 차감, 상태이상과 무등급 거부, 중복 소비, 저장 실패 복구, 디스크 재로드와 원래 저장 형식 호환을 임시 경로에서 검증한다.
- 기존 `Validate Basket and Warehouse`, `Validate Potato Starch Processing`도 통과했다. 가공 한 사이클 검증은 실제 감자를 개별 투입하도록 갱신했다.
- 실제 플레이 모드에서는 Input System 입력으로 E 진입·재진입, 마우스 호버와 클릭, 바구니 흔들기, 상태이상 거부, Esc 부분 투입 유지, 4번째 투입 후 자동 종료, E 분쇄, 저장 후 재로드를 확인했다. 실제 사용자 저장 파일 대신 프로젝트 `Temp`의 별도 저장 경로를 사용했다. 이후 리롤 키를 R로 변경했다.
