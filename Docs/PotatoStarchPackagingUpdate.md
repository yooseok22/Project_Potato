# 전분 가공·건조·포장 변경 내역

수정일: 2026-10-25

연결 씬: `Assets/Scenes/Test/YoungSeok_TestScene.unity`

## 플레이 흐름

1. 기존대로 감자를 5회 분쇄·투입하고 전분이 채워진 아래 틀을 든다.
2. 가공기에 E를 한 번 누르면 H1-1 USE와 H2-1 USE가 동시에 작동한다.
3. 두 손잡이가 모두 끝나면 Water Basket Drop을 실행한다.
4. 가공기에 다시 E를 눌러 틀을 상단 받침에 걸친다. 손을 비우고 150초 건조한다.
5. 건조 완료 후 아래 물 바스켓에 E를 눌러 실제 바스켓을 손에 든다. 건조 중에는 집을 수 없다.
6. 물 바스켓을 든 플레이어가 손잡이에 E를 누르면 양쪽 손잡이를 다시 동시에 작동한다.
7. 두 손잡이가 끝나면 Dry Basket Drop으로 실제 전분 틀이 아래로 내려온다. 물 바스켓은 손에 유지된다.
8. 낙하가 끝난 뒤 가공기에 다시 E를 누르면 물 바스켓을 상단의 원래 위치에 설치하고 손을 비운다. 바닥의 전분과 전분 틀은 유지한다.
9. FBX_Starch Packaging Bundle에 E를 눌러 포장지를 한 개씩 획득한다. 손에 드는 모델은 생성하지 않는다.
10. 맨손으로 바닥의 전분 틀에 E를 눌러 포장을 시작한다. 포장지 한 개를 소비하고 3초 뒤 Strach Pack 한 개 획득을 Console에 출력한다.
11. 완료 후 다음 E 입력을 기다린다. 자동으로 다음 팩을 포장하지 않는다.
12. 한 사이클 총 5팩을 모두 포장하면 빈 틀과 설비를 초기화한다.

물 바스켓 복귀는 바스켓과 손잡이 위치만 복원한다. 전분량이나 포장 수량을 초기화하지 않으며, 모든 전분의 포장이 끝날 때까지 다음 생산은 시작할 수 없다.

## 포장 조건과 임시 수량

- Hands 슬롯을 선택하고 그 슬롯이 비어 있어야 한다. 도구를 선택하거나 물건을 들면 포장할 수 없다.
- 포장지는 플레이어별 `StarchPackagingInventory.WrapperCount`에 임시 기록한다.
- 완성품은 플레이어별 `StarchPackCount`에 임시 기록하고 Console에 획득 로그를 출력한다.
- 실제 인벤토리, 저장, 네트워크 동기화는 아직 연결하지 않는다. 플레이 모드 종료 시 임시 수량은 사라진다.
- 포장 중 추가 E 입력과 포장지 획득을 차단한다. 같은 플레이어가 다른 설비에서 중복 포장할 수도 없다.
- 포장 도중 도구를 선택하거나 플레이어/가공기가 비활성화되면 취소하고 예약한 포장지 한 개를 반환한다.
- 타이머는 기존 공정과 동일한 WorldClock을 따른다. 기본 속도 1에서 3초이며 일시정지와 테스트용 시간 진행을 반영한다.

## 애니메이션과 배치

- 기존 가공기 모델은 유지한다.
- 새로 추가된 `Assets/Fbx/Fbx/Potato Millionaire Strach Maker 1.fbx`에서 `Anim_Starch Dry Basket Drop` 클립을 가져온다. 길이는 약 0.467초다.
- Dry Basket Drop은 별도 채널로 재생하여 Water Basket Drop의 마지막 자세를 유지한다.
- Dry Basket Drop의 시작 자세에서 받침 높이를 계산한다. 현재 씬의 DryingAnchor는 약 `(7.09, 1.537, 6.92)`다.
- 상단의 운반용 본과 낙하를 담당할 원본 본의 자세를 일치시킨 뒤 다시 연결하므로 배출 시작 시 틀이 튀지 않는다.
- 마지막 낙하 자세는 지면의 원래 아래 틀 위치다. 내려온 틀의 Collider로 포장 상호작용을 받는다.
- 물 바스켓에도 독립 운반 본과 `StarchWaterBasket` 상호작용을 연결했다. 상호작용 Collider는 바스켓의 낙하 위치를 따라가고, 운반 중에는 비활성화한다.
- 물 바스켓을 복귀할 때 Water Basket Drop과 내용물, 손잡이 채널만 초기화한다. Dry Basket Drop과 전분 채우기 채널은 유지한다.
- 한 팩씩 완성할 때 틀에 남은 전분 표시도 줄인다.
- 기존 포장 프랍 묶음을 가공기 옆으로 이동했다. 포장지 묶음 중심은 약 `(9.59, 0.20, 6.92)`다.

## 연결과 검증

`Tools > Project Potato > Setup Potato Starch Test` 메뉴로 애니메이션 커브, 받침 위치, 포장지 묶음의 Collider와 상호작용, 플레이어의 임시 수량 컴포넌트를 연결한다.

`Tools > Project Potato > Validate Potato Starch Processing` 메뉴는 별도 미리보기 씬에서 전체 공정을 검증한다. 주요 항목:

- 기존 믹서기, 5회 부분 채우기, 전분 배출 및 운반 동작.
- 두 번의 손잡이 동시 작동과 중복 입력 차단.
- 건조 후 실제 물 바스켓 들기, 손에 든 바스켓의 소유자 확인, 낙하 종료 전 복귀 차단.
- 물 바스켓의 상단 복귀와 손 슬롯 해제, 바닥 전분 틀과 내용물 유지.
- 받침 높이, 원본 본 재연결 시 메시 위치 유지, 실제 메시 낙하.
- 건조/낙하 완료 전 포장 차단.
- 포장지 획득 시 손 슬롯을 사용하지 않음.
- 도구 및 물건을 든 상태 차단, 도구 변경 시 취소와 포장지 반환.
- 2.99초에는 지급 없음, 3초에 한 개 지급, 추가 대기로 자동 반복 없음.
- 5팩 포장 후 초기화와 다음 사이클 시작.

154개 검증을 통과했다. 연결된 실제 씬에서도 믹서기와 전분 틀 운반, 상단 배치, 건조, 아래 물 바스켓 조준과 들기, 손잡이 조작, 전분 틀 낙하, 물 바스켓 상단 복귀, 아래 틀 조준, 5회 개별 포장과 설비 초기화를 확인했다.
