# Player 쿼터뷰 및 농작지 범위 표시 구현 계획

## 1. 목표

Capsule 형태의 `Player`를 Plane 형태의 `Ground` 위에 배치한다. 카메라는 Player를 대각선 위에서 보는 3인칭 쿼터뷰로 설정한다. 화면 정중앙의 크로스헤어가 Ground를 가리키면, 해당 위치에 농작지로 설정할 수 있는 타일 범위를 표시한다.

마인크래프트와 코어키퍼처럼 선택 위치가 타일 단위로 이동하는 상호작용 피드백을 구현한다. 실제 지형을 복셀이나 Tilemap으로 변환하지 않고, Plane 위에 논리적인 격자를 사용한다.

이번 산출물은 계획서이며 씬과 코드는 아직 변경하지 않는다.

## 2. 확인한 프로젝트 상태

- Unity 버전: `6000.5.0f1`.
- 설치된 패키지: URP `17.5.0`, Input System `1.19.0`, uGUI `2.5.0`.
- 저장된 씬: `Assets/Scenes/YoungSeok.unity`, `Assets/Scenes/SampleScene.unity`.
- 저장된 두 씬에는 Main Camera와 Directional Light가 있으며, Player와 Ground는 없다.
- Assets의 C# 파일 검색 결과, 게임플레이 스크립트는 아직 확인되지 않았다. 기존 런타임 UI도 확인되지 않아 크로스헤어는 uGUI를 기본으로 한다.
- 실제 구현 시 열린 씬과 저장하지 않은 변경 사항을 먼저 확인하고 대상 씬을 결정한다.

## 3. 범위와 기본 가정

- ‘Player 아래 Ground’는 계층상 자식이 아닌, Player 발밑의 바닥으로 해석한다. 두 오브젝트는 독립적으로 배치한다.
- 최초 구현은 조준한 **1×1칸의 농작지 후보 영역**을 표시한다. 플레이어 주변의 모든 칸을 한꺼번에 표시하는 기능은 포함하지 않는다.
- 타일 크기는 1 Unity 단위, 상호작용 거리는 Player 기준 수평 거리 4단위를 초기값으로 한다.
- 농작지 확정 입력, 경작 상태 저장, 작물 심기, 인벤토리, 이동 조작은 이번 기본 범위에서 제외한다.
- 수치와 색상은 Inspector에서 조절할 수 있게 한다. 다중 칸 농작지는 이후 확장 가능하도록 후보 영역 계산과 표시를 분리한다.

## 4. 씬 배치

| 오브젝트 | 구성 | 초기 설정 |
| --- | --- | --- |
| Player | Capsule, 기본 Capsule Collider | 위치 `(0, 1, 0)`, 크기 `(1, 1, 1)` |
| Ground | Plane, Mesh Collider, 전용 Ground 레이어 | 위치 `(0, 0, 0)`, 크기 `(2, 1, 2)` — 약 20×20단위 |
| Main Camera | Perspective Camera, 쿼터뷰 추적 스크립트 | 아래 카메라 기준 적용 |
| FarmingPreview | 바닥 타일 외곽선과 반투명 면 | 시작 시 숨김, Collider 없음 |
| HUD / Crosshair | Screen Space Overlay Canvas, 중앙 표시 | 중앙 앵커·피벗, Raycast Target 비활성화 |

Player는 높이 2인 기본 Capsule을 기준으로 바닥에 발이 닿도록 배치한다. Ground는 Player의 이동이나 회전을 상속하지 않는다. 기존 조명과 URP 설정은 유지하면서 Player·Ground·미리보기를 구별할 수 있도록 재질을 조정한다.

## 5. 카메라와 크로스헤어

1. 카메라의 초기 각도는 내려다보기 약 45도, 수평 회전 약 45도로 설정한다.
2. 초기 시야각은 45도, 추적 기준점과의 거리는 약 10단위로 두고 실제 Game 뷰에서 조정한다.
3. 추적 기준점은 Player 발 위치에서 카메라의 수평 전방 방향으로 약 2단위 떨어진 Ground 위 지점으로 둔다.
4. 이를 통해 Player가 화면 중앙보다 아래에 보이고, 중앙 크로스헤어는 Player 앞의 바닥을 가리키게 한다.
5. Player 위치 변경에 대한 카메라 갱신 후 조준 판정을 실행하여 미리보기의 한 프레임 지연을 방지한다.
6. 크로스헤어는 작은 십자 형태로 만들고, 해상도와 화면 비율이 바뀌어도 화면 정중앙을 유지한다.

고정 쿼터뷰에서는 기본 조준 위치가 Player 앞에 유지된다. 최초 검증은 Scene 뷰에서 Player 위치를 변경하며 수행하고, 자유로운 이동·시점 입력은 별도 후속 범위로 둔다.

## 6. 조준 및 타일 판정 흐름

`화면 중앙 → 카메라 Ray → Ground 충돌점 → 격자 좌표 → 설치 가능 여부 → 미리보기 갱신`

1. 마우스 커서 위치 대신 카메라 뷰포트 중앙 `(0.5, 0.5)`에서 Ray를 만든다.
2. Player와 미리보기는 Ray 판정에서 제외한다. Ground와 장애물은 판정에 포함하여 장애물 너머의 바닥을 선택하지 않는다.
3. 최초 충돌이 지정된 Ground인지 확인한다. 충돌이 없거나 다른 물체이면 표시를 숨긴다.
4. Ground의 최소 X/Z 경계를 격자 원점으로 정의한다. 충돌점에서 원점을 뺀 뒤 셀 크기로 나누고 내림하여 정수 셀 좌표를 얻는다.
5. 표시 위치는 `격자 원점 + (셀 좌표 + 0.5) × 셀 크기`로 계산한다. 음수 월드 좌표에서도 같은 규칙을 적용한다.
6. 선택 셀 전체가 Ground 안에 들어오는지 검사한다. 바깥으로 걸치는 셀은 유효하지 않다.
7. Player 발 위치와 선택 셀 중심의 XZ 평면 거리가 상호작용 거리 이내인지 검사한다. 카메라 Ray 길이와 상호작용 거리는 별도로 관리한다.
8. 유효한 후보 셀을 재사용 가능한 단일 미리보기 오브젝트로 표시한다.

최초 Ground는 회전하지 않은 수평 Plane으로 제한한다. 이후 회전된 바닥을 지원할 때는 Ground의 로컬 좌표에서 셀 계산을 수행하도록 확장한다.

## 7. 시각적 피드백

| 상태 | 표시 |
| --- | --- |
| Ground 위, 거리 내, 셀 전체가 바닥 내부 | 초록색 외곽선 + 옅은 반투명 면 |
| Ground 위이지만 거리 초과 또는 경계 밖으로 걸침 | 빨간색 외곽선 + 옅은 반투명 면 |
| Ground 미적중 또는 장애물에 가림 | 미리보기 숨김 |

- 면은 Ground에서 약 0.02단위 띄워 깊이 충돌에 의한 깜빡임을 줄인다.
- URP 호환 재질을 사용하고 그림자 생성은 비활성화한다.
- 미리보기는 월드 공간에 배치하여 쿼터뷰 원근과 바닥 방향을 따른다.
- 매 프레임 오브젝트나 재질을 생성하지 않고, 셀 또는 상태가 바뀌었을 때 표시를 갱신한다.

## 8. 예정 파일과 역할

| 경로 | 역할 |
| --- | --- |
| `Assets/Scripts/Camera/QuarterViewCamera.cs` | Player 기준 쿼터뷰 위치 및 구도 유지 |
| `Assets/Scripts/Farming/GroundGrid.cs` | 셀 크기·원점·경계 및 좌표 변환 |
| `Assets/Scripts/Farming/FarmingTargetSelector.cs` | 중앙 Ray, 거리 검사, 후보 셀 및 유효성 계산 |
| `Assets/Scripts/Farming/FarmingPreviewView.cs` | 타일 외곽선·면 위치와 상태 색상 표시 |
| `Assets/Materials/Farming/` | 미리보기용 URP 재질 |
| 구현 시 확인한 대상 씬 | Player, Ground, 카메라, HUD 및 참조 연결 |

필요 이상의 프레임워크나 추가 패키지는 도입하지 않는다. 씬 변경은 구현 단계에서 Unity Editor의 현재 상태를 확인하고 Unity 도구를 통해 수행한다.

## 9. 구현 순서

1. 열린 씬, 기존 오브젝트, 카메라, 레이어와 미저장 변경을 확인한다.
2. Player와 Ground를 생성하고 바닥 접촉 위치와 충돌체를 확인한다.
3. 카메라를 배치하여 Player와 전방 조준 지점이 함께 보이는 구도를 맞춘다.
4. uGUI 중앙 크로스헤어를 생성한다.
5. Ground 격자 좌표 변환과 중앙 Ray 판정을 연결한다.
6. 타일 미리보기와 유효·무효·숨김 상태를 구현한다.
7. Inspector 참조를 연결하고 Play 모드에서 아래 기준을 검증한다.

## 10. 완료 기준

- [ ] `Player`라는 Capsule이 `Ground`라는 Plane 위에 정확히 서 있다.
- [ ] Game 뷰가 Player를 대각선 위에서 보는 3인칭 쿼터뷰이다.
- [ ] Player가 조준 타일을 가리지 않고, 초기 중앙 Ray가 거리 내의 Ground를 가리킨다.
- [ ] 크로스헤어는 16:9와 4:3 화면에서 모두 정중앙에 있다.
- [ ] Ground 조준 시 바닥에 맞춰진 1×1칸 미리보기가 보인다.
- [ ] 셀 경계 이동 시 표시가 연속적으로 미끄러지지 않고 칸 단위로 바뀐다.
- [ ] 음수 좌표와 Ground 가장자리에서도 셀 정렬과 경계 판정이 일관된다.
- [ ] 거리 초과는 빨간색, Ground 미적중과 장애물 가림은 숨김으로 처리된다.
- [ ] 미리보기가 Ray에 재검출되지 않고 바닥과 깜빡이지 않는다.
- [ ] Play 모드에서 컴파일 오류와 누락 참조 오류가 없다.

좌표 계산은 원점 양쪽, 셀 경계, 바닥 가장자리 사례로 확인한다. 구도·색상·깜빡임은 Game 뷰에서 직접 검증한다.
