# 바구니 HUD / 태블릿 UI 연결 내역

2026-11-11. `Tablet 기획서.pdf` 2~10쪽을 화면 배치·색상·탭·조작 기준으로 사용했다. 제공된 `Assets/UI/Tablet_UI.png`, `basket_tool.png`의 스프라이트를 사용한다. 가이드의 재배 그림은 PDF 7쪽에서 추출했다.

## 실행과 조작

- `YoungSeok_TestScene`을 실행하고 **Tab**으로 태블릿을 열고 닫는다. **Esc**, 오른쪽 위 **×**로도 닫는다.
- 열려 있는 동안 이동·도구·줍기 입력을 막고 마우스를 해제한다. 닫으면 마우스 잠금과 게임 조작을 복구한다. 바구니 선택·기계 건설 등 다른 작업 화면이 열려 있으면 중복으로 열지 않는다.
- 왼쪽 아이콘 순서는 홈 / 상점 / 연구 / 가이드 / 설정이다.
- 상점: 물품·기계 탭 → 상품 선택 → **+ / −** → **구매**. 총액 옆 **×**는 장바구니 전체 비우기다. 잔액 부족 시 구매할 수 없다.
- 연구: 노드에 마우스를 올리거나 클릭하면 설명을 표시한다. **E** 또는 연구 버튼으로 연구한다. 선행 연구와 RP를 검사한다. 드래그로 이동하고 휠·**+ / −**로 확대·축소한다.
- 가이드: 재배 / 가공 / 자동화 분류, 왼쪽 글 목록, **A / D** 및 화살표로 페이지를 이동한다.
- 설정: 일반 / 그래픽 / 오디오 탭에서 드롭다운·슬라이더·ON/OFF 버튼을 사용한다.

## 바구니 단계

10개 용량에서 경계값 50%와 70%는 다음 단계가 시작되는 값으로 처리했다. 담기·꺼내기·수확·저장 불러오기 후 실제 바구니 수량을 읽는다.

| 수량 | 비율 | 이미지 |
|---|---|---|
| 0~4개 | 0~49% | `basket_tool_2_0` |
| 5~6개 | 50~69% | `basket_tool_2_1` |
| 7~9개 | 70~99% | `basket_tool_2_2` |
| 10개 | 100% | `basket_tool_2_3` |

## 데이터 연결과 저장 위치

**외부 DB는 사용하지 않는다. 사용자 요청대로 기존 로컬 세이브의 슬롯 1·2에 연결했다.**

| 화면 데이터 | 실제 데이터 원본 / 동작 | 저장 |
|---|---|---|
| 시간, DAY | 기존 `WorldClock` | 기존 농사 세이브 |
| 농장 이름 | 입력 후 24자 이내 검사 | 해당 슬롯의 태블릿 프로필 |
| MONEY / 상점 잔액 | 태블릿 프로필의 `money` | 해당 슬롯 |
| YIELD | 직접 수확한 감자 누적 개수 | 해당 슬롯 |
| 농장 등급, 경험치 | 감자 1개 수확당 XP 5, 100 XP마다 1레벨 | 해당 슬롯 |
| RP | 수확 감자 1개당 RP 1 | 해당 슬롯 |
| 밭 상태 | 실제 재배 작물 개수, `GroundGrid` 칸 수·면적 | 기존 농사 세이브에서 조회 |
| 공장 생산량 | 실제 `PotatoStarchProcessor.TotalProducedPackCount` 합계 | 기존 가공 세이브에서 조회 |
| 미니맵 | 현재 밭의 땅·작물 상태, 자동화 기계 위치, 플레이어 위치 | 화면에서 실시간 생성 |
| 상점 상품·가격·설명 | `TabletCatalog.asset` | 프로젝트 설정 에셋 |
| 구매 물품·기계 대수 | 금액 차감과 재고 증가를 한 번에 처리 | 해당 슬롯 |
| 연구 목록·비용·효과 | `TabletCatalog.asset` | 설정 에셋 |
| 연구 완료 여부 | RP 차감과 해금을 한 번에 처리 | 해당 슬롯 |
| 가이드 | 현재 플레이 조작에 맞춘 재배·가공·자동화 글 10개 | 설정 에셋 |
| 일반·그래픽·오디오 설정 | 카메라·화면·프레임·AudioListener/AudioSource | PC별 별도 JSON |

기존 `SaveGameController` → `SaveSlotService` → `InventorySaveSection` 경로를 사용한다. `ownerId = tablet:local-player`, `itemId = tablet_profile`, `propertiesVersion = 1`의 인벤토리 항목에 프로필 JSON을 저장한다. 기존 슬롯 파일 형식을 유지하며, 태블릿 데이터가 없는 이전 저장은 기본 프로필을 만든다.

슬롯 저장 위치: `Application.persistentDataPath/Saves/slot-1.json`, `slot-2.json`. 이 프로젝트의 Windows 기본 위치는 `%USERPROFILE%/AppData/LocalLow/DefaultCompany/Project_Potato/Saves`다.

설정 위치: `Application.persistentDataPath/Settings/tablet-settings.json`. 설정은 슬롯과 분리하여 유지한다. 짧은 지연 후 저장하고 태블릿 종료 시에도 저장한다. 임시 파일 작성 후 이전 파일을 교체한다.

구매·연구·이름 변경은 저장 실패 시 메모리의 잔액·재고·RP·해금을 복구한다. 직접 심기는 씨감자와 밭을, 수확은 바구니·밭·누적 수확·XP·RP를 같은 저장 작업에 묶어 실패 시 복구한다. 로컬 저장은 기존 시스템과 동일하게 오프라인에서 동작한다.

## 상점 및 연구의 실제 플레이 연결

- 씨감자: 플레이어가 직접 심을 때 1개 소비한다. 부족하면 심지 않는다. 기존 로봇 파종은 기존 작업 로직을 유지한다.
- 포장지: 가공 작업대의 포장지 묶음에서 꺼낼 때 구매 재고 1개를 소비한다. 포장 취소 시 현재 손에 든 포장지를 계속 사용할 수 있다.
- 기계: `[B]` 자동화 모드에서 구매한 종류별 보유 대수만큼 동시에 설치할 수 있다. 철거하면 설치 가능한 대수가 다시 늘어난다. 구매 대수는 슬롯에 저장한다. 기계 배치·배선·로봇 작업 자체의 영구 저장 기능은 기존 자동화 시스템의 범위를 유지한다.
- 성장 속도: 단계별 1.25 / 1.5 / 1.75배. 연구 직전까지 자란 양을 보존하며 이후 속도를 변경한다. 작물 저장 데이터에 배속을 추가했으며 이전 데이터의 누락·0 값은 1배로 복원한다.
- 생명력: 새 작물 최대 체력 +10 / +20 / +30%.
- 벌레 예방: 발생 확률을 기본 확률의 75 / 50 / 25%로 변경한다.
- 상점 할인: 전체 상품 5 / 10 / 15% 할인.
- 수확량: 살아 있는 작물 수확 시 감자 +1 / +2 / +3개. 바구니 공간 검사에도 반영한다.

## 설정 적용 범위

- 카메라 감도·마우스 감도: 기존 시점 회전 감도에 두 설정을 곱하여 적용한다.
- 카메라 흔들림: 이동할 때 손 모델의 흔들림을 켜고 끈다.
- 시야각: 실제 플레이 카메라 FOV에 즉시 적용한다.
- 화면 모드·해상도: 설정을 저장하고 빌드된 실행 파일에서 적용한다. Unity Editor의 창 크기는 강제로 바꾸지 않는다.
- 최대 프레임·수직 동기화: `Application.targetFrameRate`, `QualitySettings.vSyncCount`에 적용한다. VSync가 켜지면 프레임 제한보다 모니터 동기화가 우선할 수 있다.
- 마스터 볼륨: `AudioListener.volume`에 적용한다. 개별 AudioSource 이름/클립명에 `music`·`bgm`이 있으면 음악, `ambient`·`environment`가 있으면 환경음, 나머지는 효과음으로 분류한다. 기존 원래 볼륨을 기준으로 적용하여 슬라이더 조작 때마다 볼륨이 중복 감소하지 않게 했다.
- 한국어 UI를 사용한다. 언어 선택은 현재 지원 언어인 한국어 한 항목이다.

## 기존 시스템이 없어 예시 또는 설정 저장으로 남은 항목

- **날씨:** 프로젝트에 날씨 시뮬레이션이 없어 프로필의 날씨를 표시한다. 기본은 Sunny다. Sunny / Cloudy / Rainy / Hot 모두 흰색 `_1` 아이콘을 사용한다. Thunder는 제공된 흰색 단일 아이콘을 사용한다. 자동 날씨 변화는 연결되지 않았다.
- **관심 주식:** PBCO 218.5 $, +0.52%와 차트는 PDF에 맞춘 고정 예시다. 실제 주식·거래·외부 시세 DB와 연결하지 않았다.
- **공장 판매액:** 현재 판매 시스템이 없어 0 M을 표시한다. 실제 가공 생산량은 연결되어 있다.
- **마이크:** 실제 PC 장치 목록을 읽고 장치·말하기 방식·입력 볼륨을 설정 파일에 저장한다. 현재 프로젝트에 음성 채널 송수신 구현이 없어 다른 플레이어와의 음성 통신에는 아직 연결되지 않는다.

## 수정할 에셋과 검증

- 화면 프리팹: `Assets/UI/Tablet/TabletUI.prefab`.
- 가격·글·연구·새 슬롯 초기값: `Assets/UI/Tablet/TabletCatalog.asset`.
- 초기값은 테스트 가능한 임시 밸런스로 **1,000 M / RP 100 / 씨감자 100개**다. 기존 세이브에 태블릿 데이터가 있을 때는 덮어쓰지 않는다.
- UI 버튼 연결은 직렬화된 `TabletControl`을 통해 프리팹 저장·다시 실행 후에도 유지된다. Player 프리팹과 현재 테스트 씬에 연결했다. EventSystem이 없는 다른 씬에서도 로컬 플레이어가 최초로 열 때 생성한다.
- 에디터 생성 도구: `Tools > Project Potato > Build Tablet UI`. 화면 프리팹을 다시 생성하는 명시적 도구이므로 직접 수정한 화면을 유지하려면 실행하지 않는다. 일반 플레이에는 필요 없다.

검증 완료: Unity 스크립트 컴파일, 태블릿 Play 검사 225개(화면 글자 영역 검사 포함), 실제 Input System 마우스 검사 6개. 구매 수량·부족 잔액·저장 실패 복구·연구 선행 조건·실제 성장 배속·수확 XP/RP·슬롯 분리/재로드·설정 저장·Tab/Esc·바구니 0~10개 전체 경계값을 검사했다. 테스트 저장은 프로젝트 `Temp`로 우회했으며 사용자의 실제 세이브를 수정하지 않았다.

기존 `PotatoFarmingChecks`(기본/벌레/흙 덮기/멀칭), `PotatoHarvestRevisionChecks`, `PotatoStorageChecks`, `SaveGameChecks`도 통과했다. 7개 화면을 Play 화면 캡처로 확인했다. 실행 가능한 검사 스크립트는 `AgentScripts/TabletPlayChecks.cs`, `TabletPointerChecks.cs`에 있다.
