# 감자 수확 변경 내역

수정일: 2026-10-25

연결 씬: `Assets/Scenes/Test/YoungSeok_TestScene.unity`

## 작업 범위

수확·농지·플레이어 밟힘·보상·저장 연동을 수정했다. `BoarController`, `BoarSpawnManager`, `BoarChargeHitbox`와 기존 성장·체력 원본 `PotatoFarmingSystem`, `PotatoGrowthRules`, `PotatoFarmingChecks`는 수정하지 않았다. 체력 변경은 기존 `TryDamage`를 호출하고, 사망은 기존 `FarmingTileDied` 이벤트에서 처리한다.

## 수확 흐름

| 낫으로 잎을 베는 단계 | 판정 | 피해 |
| --- | --- | ---: |
| 큰 잎 6개 | 이른 수확 | 20 |
| 싱싱한 큰 잎 6개 | 적기 수확 | 0 |
| 시든 잎 6개 | 늦은 수확 | 40 |

낫 좌클릭으로 잎을 베면 수확 시기를 기록하고 해당 작물의 성장 진행을 멈춘다. 이후 포크 좌클릭으로 땅을 파서 감자를 드러내고, 맨손으로 E를 눌러 수확한다. 시든 잎 단계는 이미 최종 성장 단계이므로 기존 성장 API의 최종 단계 동작을 사용한다.

심은 감자마다 노출 깊이를 1~3 중 한 번 정해 그리드에 저장한다. 포크질마다 다시 추첨하지 않는다. 흙을 덮었는지와 관계없이 같은 깊이 규칙을 사용한다.

- 깊이 1: F → HY
- 깊이 2: F → HN → MY
- 깊이 3: F → HN → MN → LY
- 드러난 HY에 추가 포크질: ME, 상처 입은 상태
- 드러난 MY 또는 LY에 추가 포크질: LE, 상처 입은 상태
- ME/LE에서 다시 포크질: 감자 폐기, 보상 없음, N_015

## 반복 밟힘과 체력 0

`CropTrampleController`는 로컬 플레이어가 지면에 접촉한 작물 셀에 진입할 때 10 피해를 요청한다. 동일 셀에서 서 있는 동안에는 반복하지 않는다. 벗어났다가 재진입하거나 점프 후 다시 착지하면 새 피해를 준다. 성장 정지 후에도 살아 있는 작물은 피해를 받는다.

체력은 0 미만으로 내려가지 않는다. 체력 0 이벤트에서는 재배 데이터와 수확 정보를 제거하고 보상 없이 GD F로 전환한다. 성장 처리 도중 벌레/흙 미덮음으로 사망해도 남은 성장 콜백이 사망 타일을 덮어쓰지 않도록 처리한다.

| 상황 | 결과 타일 |
| --- | --- |
| 체력 0 | `Assets/Fbx/Tile/v2_reallast/FBX_Farm Land GD F.prefab` |
| GD F에 괭이 좌클릭 | G_001 |
| 반복 포크질로 감자 폐기 | N_015 |
| E 수확 완료 | G_001 |

포크 폐기용 `HarvestClearedField` 상태는 주변 셀과 관계없이 정확히 N_015 메시를 선택한다. 괭이로 다시 심을 자리를 만들 수 있다.

## 보상

| 최종 체력 | 총 획득 개수 | 개별 감자의 별 등급 |
| --- | --- | --- |
| 100 | 2~3 | 1성 70%, 2성 20%, 3성 10% |
| 90~99 | 1~3 | 1성 85%, 2성 15% |
| 80~89 | 1~2 | 1성 100% |
| 1~79 | 1 | 1성 100% |
| 0 | 0 | 보상 없음 |

총 획득 개수는 범위 안에서 동일 확률로 추첨한다. 체력 100은 2개/3개 각각 50%, 90~99는 1개/2개/3개 각각 1/3, 80~89는 1개/2개 각각 50%다. 개수가 정해진 뒤 **각 감자의 별 등급을 독립적으로 추첨**한다. 사용자는 별 등급 확률을 기존 70/20/10%, 85/15%로 유지하는 것으로 확인했다.

상태 이상이 있는 작물은 총 개수와 별 등급을 먼저 추첨하고 다음 표로 상태 이상 감자 개수를 정한다. 해당 개수만큼 임의의 감자를 선택하고 작물의 상태를 붙이며, 나머지는 정상 감자로 처리한다. 복수 상태는 선택된 감자에 함께 유지한다.

| 체력 | 총 개수 | 상태 이상 감자 개수 확률 |
| --- | --- | --- |
| 90~99 | 3 | 3개 40%, 2개 40%, 1개 20% |
| 90~99 | 2 | 2개 50%, 1개 50% |
| 90~99 | 1 | 1개 100% |
| 80~89 | 2 | 2개 70%, 1개 30% |
| 80~89 | 1 | 1개 100% |
| 1~79 | 1 | 1개 100% |

상태 이상 종류는 벌레 먹음, 녹색, 상처 입은, 싹난이다. 썩음은 수확 결과에서 제외한다.

사용자 확인으로 체력 100에서는 **상태 이상 개수에 한해 90~99 표를 적용**하는 것으로 확정했다. 체력 100의 총 개수와 별 등급 확률은 원래 규칙을 유지한다. 이로써 완전한 체력의 감자도 추가 포크질의 상처가 수확 결과에 반영된다.

성장 소유자의 상태 enum을 수정하지 않고 `HarvestedPotatoCondition`으로 개별 보상 상태를 표현한다. 기존 벌레 먹음·녹색·상처 입은 상태는 기존 재배 데이터에서 연결한다. 싹남 발생 시스템은 `PotatoHarvestCoordinator.TryAddHarvestCondition`으로 상태를 전달할 수 있으며 저장·수확에 반영된다. 싹남 발생 조건과 실외 부패 시간은 미정이므로 임의의 타이머를 추가하지 않았다.

수확 콘솔에는 수확 시기, 굴착 상태, 체력, 총 개수, 각 별 등급의 개수, 정상/상태 이상 개수와 개별 감자 상태를 출력한다. 실제 인벤토리 지급은 연결하지 않는다.

## 저장과 검증

그리드 저장 데이터에 `exposureDepth`를 추가한다. 기존 저장 파일에 값이 없으면 현재 파낸 단계와 일치하는 깊이로 복원한다. 성장 정지·체력·수확 시기와 개별 보상에 전달할 상태도 저장 및 복원된다. 사망 작물은 재배 목록에서 제거하고 GD F 타일만 저장한다.

- `Tools > Project Potato > Connect Potato Harvest Changes`: 현재 씬에 수확 조정 컴포넌트, 반복 밟힘, GD F 모델을 연결하고 저장한다.
- `Validate Revised Potato Harvest`: 177개 검증 통과. 균등 개수 추첨, 감자별 독립 등급, 짧은 지면 접촉 끊김과 실제 재착지, 체력 80 재현을 포함한다.
- 기존 `Validate YoungSeok Potato Harvest`: 40개 검증 통과.
- `Validate Save and Load`: 사망 데이터 정리 규칙에 맞춰 갱신한 44개 검증 통과.
- 기존 성장·체력 검증: 92개 통과. 벌레, 흙 미덮음, 멀칭 검증도 통과.

실제 씬의 캐릭터 접촉으로 최초 진입·서 있기·재진입, 세 수확 성장 단계의 반복 밟힘, 체력 0과 GD F 렌더링, 괭이 복구 입력, 낫/포크/E 입력 경로와 수확 콘솔을 확인했다.

## 정상 굴착 수확에서 체력 80이었던 원인

사용자 플레이의 실제 Console 로그를 확인했다.

- `TileMap (27,25)`: 적기 수확, 굴착 정상, HP 80, 상태 벌레 먹음+녹색. 벌레를 기한 내 제거하지 않아 -10, 흙을 덮지 않아 -10이 적용된 결과다.
- `TileMap (27,19)`: 밟힘으로 100→90이 기록되었고, 수확 결과 HP 80에 녹색 상태가 있었다. 밟힘 -10과 흙 미덮음 -10의 결과다. 추가 포크질에 따른 상처는 HP를 별도로 차감하지 않는다.

적기에 정상적으로 파내는 것은 기존 재배 피해를 회복하지 않는다. 벌레 방치와 흙 미덮음을 재현한 검증에서도 낫 사용 직전 HP 80, 적기 수확 시기 피해 0, 낫 사용 후 HP 80임을 확인했다. 잎을 벨 때 선택된 수확 시기, 시기 피해, 전후 체력과 재배 상태를 Console에 추가했다.

또한 실제 로그에는 같은 셀에서 짧은 간격으로 밟힘이 반복된 기록이 있었다. 작은 흙더미를 지날 때 CharacterController의 지면 접촉이 한두 프레임 끊겨도 같은 셀 접촉을 유지하도록 보정했다. 0.15초 이상 실제 공중에 있다가 같은 작물에 착지하면 새 피해가 발생하며, 다른 셀로 나갔다 재진입하는 경우는 즉시 다시 피해를 준다.
