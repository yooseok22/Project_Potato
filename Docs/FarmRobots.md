# 농장 로봇

## 확정 규칙과 첫 구현

- 감자 파종 로봇, 방제 드론, 멀칭 로봇을 기존 B 건설 모드에서 설치한다. 충전소는 `BasicSoil` 일반 땅에만 설치 가능하다. 로봇은 밭 위로 이동한다.
- 충전소에는 발전기 코드를 연결해야 한다. 전력이 부족하면 충전이 진행되지 않는다. 초기 배터리도 충전한 뒤 출발한다.
- 소형은 1회 왕복 최대 10칸 / 충전 60초, 중형은 25칸 / 90초, 대형은 60칸 / 120초다. 한 번 성공한 칸은 같은 왕복에서 중복 작업하거나 중복 차감하지 않는다.
- 작업 경로의 첫 타일은 충전소와 떨어진 위치에도 지정할 수 있다. 이후 기존 타일의 상하좌우에 면을 맞대어 한 칸씩 추가하며, ㄱ자·ㄷ자·갈림길·고리 형태도 가능하다. 충전소와 작업 경로 사이의 접근·복귀 구간은 격자로 길을 찾아 이동만 하며 작업하지 않는다. 로봇은 인접 타일의 추가 순서에 따라 가지를 방문하고 지나온 길을 되짚어 모든 지정 타일을 순회한 후 첫 타일로 돌아와 충전소로 복귀한다. 양쪽 이동 모두 파란 구간에서 작업한다. 고리에서는 같은 타일을 새 방문 대상으로 무한 반복하지 않는다. 최대 작업량에 도달하면 추가 작업을 멈추고 순회를 완료하며, 충전 후 남은 일을 이어서 한다.
- 충전이 완료되고 유효한 작업이 있을 때만 자동 출발한다. 경로가 모두 미작업이거나 파종·멀칭·예방할 작물이 없으면 대기한다.
- 지상 로봇은 발전기·물탱크·스프링클러 등 설치물을 상하좌우 격자 탐색으로 우회하며 작업을 계속한다. 설치물로 막힌 작업 칸이나 접근 불가능한 칸은 해당 방문에서 건너뛰고, 우회 이동 중에는 작업하지 않는다. 운행 도중 우회 길에 장애물이 생기면 다시 길을 찾는다. 보급품이 부족하면 작업을 중단하고 충전소로 복귀한다. 복귀 역시 장애물을 우회하며, 모든 복귀 길까지 막혀 있으면 멈추고 경로가 생기는지 주기적으로 재확인한다. 드론은 기존 비행 높이에서 지상 설치물 위를 이동한다.
- 이동하는 로봇 본체끼리는 물리 충돌과 경로 장애물 판정을 모두 무시하여 서로 통과한다. 충전소·시설물·플레이어 등 다른 대상은 기존 판정을 유지한다.
- 현재 씨감자·비닐·약은 합의에 따라 모두 무소모다. 실제 바구니 보급과 업그레이드 박스 자동 보급은 후속 작업이다.

## 조작

| 입력 | 기능 |
| --- | --- |
| B | 기존 무료 건설 모드 |
| Z / X | 기존 기계와 로봇 충전소 선택 |
| V | 로봇 소형 → 중형 → 대형 변경 |
| 좌클릭 | 초록 미리보기 위치에 설치 |
| 충전소 또는 대기 로봇을 보고 E | 설정하기. 운행 중에는 변경할 수 없음 |
| 설정 중 좌클릭 | 지상 로봇: 원하는 곳에 첫 타일을 선택하고 기존 타일의 상하좌우로 한 칸씩 추가. 왕복 순회는 자동 생성 |
| 경로 칸 우클릭 | 파란색 작업 / 빨간색 이동만 전환 |
| 드론 설정 중 좌클릭 2회 | 정사각형 살포 영역의 두 꼭짓점 지정. 최대 4개 |
| 드론 영역 우클릭 | 해당 영역 삭제 |
| Backspace | 지상 경로의 마지막 타일 취소 / 드론의 마지막 지정 취소 |
| Enter | 설정 확정 |
| Esc / B | 편집 취소. 이전 설정 유지 |

스프링클러는 갈아놓은 농사 타일에도 설치할 수 있다. 농사 타일의 울퉁불퉁한 메시 대신 그리드 기준 높이에 설치하며, 기존 설치물과의 중복 설치 검사는 유지한다.

각 작업 타일은 기존 타일 중 하나와 면을 맞대어야 한다. 경로 전체가 일직선일 필요는 없으며, 방향을 꺾거나 어느 타일에서든 갈림길을 만들 수 있다. 대각선만 닿거나 다른 타일과 떨어진 타일은 추가할 수 없다. 충전소에 붙어 있거나 충전소와 같은 행·열에 있을 필요는 없다. 충전소와 작업 경로 사이 및 장애물 우회 복귀에서는 작업하지 않는다. 경로 편집 동안 농기구·물건 줍기·기존 E 상호작용 입력을 중복 실행하지 않는다.

## 로봇별 작업

### 파종

일반 땅과 빈 밭을 갈고 구멍을 파서 감자를 심고 흙을 덮는다. 파종할 때 대각선을 포함한 주변 8칸의 일반 땅도 밭으로 간다. 주변 칸은 작업 범위에 포함하지 않아도 되며, 추가 작업량이나 씨감자를 소비하지 않는다. 미작업으로 지정한 주변 칸도 땅만 갈고 감자는 심지 않는다. 기존 작물·구멍 등 이미 준비된 상태는 유지하며, 그리드 밖은 건너뛴다. 기존 감자가 있으면 덮어쓰지 않는다. 작물 등록과 수확 상태 초기화는 기존 농사 시스템을 사용한다. 물주기는 별도이며, 파종 직후 자동 물주기를 추가하지 않는다.

### 멀칭

기존 `TryApplyMulchingFilm`을 사용한다. 심은 직후부터 새싹 단계까지만 작업 가능하며, 죽은 작물·성장이 정지된 작물·이미 비닐이 적용된 작물은 제외한다. 실제 아이템 연결 후 성공한 한 칸당 비닐 1개를 소비하는 인터페이스다.

### 방제 드론 — 조정 가능한 임시 수치

설정한 네모 영역 중앙으로 날아가 작물에 예방약을 순차 살포하고 충전소로 돌아와 착륙한다. 각 영역 내 성공한 작물 칸이 공통 최대 작업량에 포함된다. 겹치는 영역의 같은 작물에는 중복 적용하지 않는다.

| 항목 | 소형 | 중형 | 대형 |
| --- | --- | --- | --- |
| 영역 한 변 최대 길이 | 3칸 | 5칸 | 7칸 |
| 충전소 기준 지정 거리 | 8칸 | 12칸 | 16칸 |
| 최대 영역 수 | 4개 | 4개 | 4개 |
| 예방 지속 시간 | 게임 월드 시간 180초 | 180초 | 180초 |

지정 거리는 충전소에서 각 꼭짓점까지 X·Z축 거리 중 큰 값으로 계산한다. 비행 높이는 지면에서 3m다. 이동 속도는 기본 2m/s, 칸당 작업 시간은 0.5초다. 모두 수정 가능하다.

예방은 기존 해충 발생 판정 시점에 유효하면 발생을 막는다. 이미 붙은 해충이나 `BugEaten` 상태를 치료하지 않는다. 보호가 유지 중인 작물은 재살포하지 않는다. 현재 농사 시스템은 성장 80초에서 해충 발생을 한 번 판정하므로, 판정이 끝난 작물은 예방 대상에서 제외한다. 예방 만료 시각은 기존 작물 저장 데이터에 포함된다.

## 튜닝과 아이템 연결

`Tools > Project Potato > Create or Select Robot Settings`로 `Assets/Resources/Automation/FarmRobotSettings.asset`을 생성하거나 선택한다. Inspector에서 크기별 최대 작업량·충전 시간·속도·작업 시간·드론 영역·예방 시간을 수정하면 다음 플레이부터 적용한다. 설정 에셋이 없으면 코드의 기본 설정을 사용한다.

`FarmRobotStation.BindSupplies`에 `IFarmRobotSupplies`를 구현한 MonoBehaviour를 연결하고 설정의 `unlimitedSupplies`를 끄면 실제 보급품 검사를 사용할 수 있다. 현재 API는 성공한 칸당 해당 역할의 재료 1개를 소비한다. 아이템 어댑터는 같은 메인 스레드 작업 안에서 `HasSupply`와 `TryConsumeSupply`의 일관성을 보장해야 한다. 실제 인벤토리·씨감자 바구니·근처 보급 박스는 아직 연결하지 않았다.

## 검증과 범위

- 로봇 50개 검증과 기존 자동화·저장 회귀 검증을 통과했다. 주변 8칸 자동 경작·작업량 유지·그리드 경계·기존 작물과 구멍 보존, 경사진 밭의 스프링클러 설치 및 중복 설치 거부를 검사한다. 상하좌우로 연결된 꺾임·분기·고리 범위를 순회하고, 대각선으로만 닿거나 떨어진 타일은 거부하는 것을 검사한다. 플레이 검증에서도 충전소와 떨어진 꺾인 범위까지 이동한 뒤 파종·미작업 칸 제외·왕복 및 충전소 귀환을 확인했다. 범위 밖 접근·복귀 중에는 작업하지 않는다. 발전기·물탱크·스프링클러를 우회하며 뒤쪽 칸까지 작업하고 설치물 칸과 우회 구간에는 심지 않는 것을 플레이에서 확인했다. 드론 예방과 착륙, 복귀길까지 막았을 때 장애물을 우회하는 검사도 포함한다.
- `Tools > Project Potato > Validate Farm Robots`: 임시 프리뷰 씬에서 경로, 작업 칸, 충전, 왕복, 작업량, 파종·멀칭·예방을 검증한다.
- `Tools > Project Potato > Run Farm Robot Play Checks`: 임시 플레이 장면에서 실제 프레임 이동·급수와 분리된 파종·드론 살포와 착륙·장애물 우회 복귀를 검증하고 자동으로 플레이를 종료한다. 기존 씬과 플레이어 저장 파일을 수정하지 않는다.
- 로봇 외형은 교체 가능한 임시 블록 모델이다. 현재 평면 농사 그리드와 싱글플레이를 대상으로 한다. 로봇·충전소·경로·충전량 자체의 저장 및 멀티플레이 동기화는 기존 자동화와 마찬가지로 후속 범위다. 예방 효과는 작물 저장과 함께 유지된다.
