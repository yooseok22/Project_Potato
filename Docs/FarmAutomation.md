# 농장 자동화 — 첫 싱글플레이 구현

합의한 범위: 무한 전력·물 공급, 무료 설치·철거, 싱글플레이. 농사 시스템이 있는 씬에서 플레이하면 `FarmAutomation`과 플레이어 조작 컴포넌트가 자동 생성된다. 씬·프리팹을 수동으로 수정할 필요가 없다.

## 조작

| 입력 | 기능 |
| --- | --- |
| B | 건설 모드 열기 / 닫기. 손에 물건을 들고 있으면 먼저 내려놓기 |
| Z / X | 발전기 → 물탱크 → 스프링클러 → 작물 이동 레일 선택 |
| R | 설치 방향 90도 회전 |
| 좌클릭 | 초록색 설치 미리보기 위치에 무료 설치 |
| 공급 장치를 보고 E | 사용하지 않은 코드·호스 꺼내기 |
| 줄을 든 상태로 바닥 우클릭 | 중간 고정점 추가 |
| 줄을 든 상태로 기계를 보고 E | 입력 단자에 연결 |
| Backspace | 마지막 고정점 제거. 고정점이 없으면 들고 있는 줄 회수 |
| F | 바라보는 기계에 연결된 줄 전체 회수 |
| Delete | 바라보는 기계 철거 및 연결 회수 |

건설 중에는 기존 농기구·줍기·던지기·E 상호작용이 중복 실행되지 않는다. 이동과 카메라 조작은 유지한다. 메뉴나 태블릿을 열면 건설 입력이 일시 정지한다.

설치 미리보기에는 타일 테두리와 함께 기계별 방향 화살표·한글 표기가 나타난다. 발전기·물탱크는 단자가 있는 앞면, 레일은 실제 이동 방향, 스프링클러는 좌·우 살수 방향을 표시한다. R로 회전하면 방향 표시도 함께 회전하며, 설치할 수 없는 위치에서는 빨간색으로 바뀐다.

## 구현 내용

- 발전기: 독립 코드 3개. 물탱크: 독립 호스 4개. 꺼내 든 줄도 단자를 점유하며, 취소·회수·철거하면 반환한다.
- 기계당 전기 입력 1개, 물 입력 1개. 공급 종류가 다르거나 이미 사용 중인 입력에는 연결할 수 없다.
- 연결 길이는 공급 단자 → 각 고정점 → 대상 단자의 직선 구간 길이 합으로 제한한다. 고정점을 추가해 사거리를 늘릴 수 없다. 늘어진 렌더링 곡선 길이는 계산에 포함하지 않는다.
- 줄에는 콜라이더가 없다. 고정점 사이가 바닥에 내려앉고 조금 흔들리는 시각 효과를 사용한다. 실제 로프 강체 시뮬레이션은 아니다. 장애물 관통 방지·모서리 자동 감기는 후속 범위다.
- 스프링클러: T자 막대의 로컬 X축을 따라 양쪽에 물을 뿌린다. 전력 100%와 호스 연결이 모두 있어야 작동한다. `GroundGrid.TryWater`와 해당 `PotatoFarmingSystem.TryWater`를 호출해 실제 성장 타이머를 시작한다. 죽은 작물·이미 물을 준 작물은 건드리지 않는다.
- 스프링클러 기둥·발전기·물탱크는 물리 충돌 및 NavMesh carving으로 이동을 막는다. `SetSprinklerPassThroughUnlocked(true)`는 기둥을 트리거로 바꾸고 NavMesh 장애물을 꺼서 통과를 허용한다. 연구 트리 자체는 연결하지 않았다.
- 레일: 맞닿은 상하좌우 블록끼리 전력을 공유한다. 대각선·빈칸·높이가 다른 레일은 연결되지 않는다. 레일 방향은 물체 운반 방향이고 전기 전달은 연결망의 모든 방향으로 가능하다. 회전시켜 코너를 만들 수 있다.
- 발전기 용량을 연결된 스프링클러와 레일 전체 수요로 나눈다. 같은 발전기의 여러 코드가 같은 레일망에 연결되어도 용량이 복제되지 않는다. 서로 다른 발전기는 레일망의 공급 용량을 합산한다.
- 레일에는 공급 지점에서 한 칸 이동할 때마다 감쇠가 적용된다. 여러 공급 경로 중 가장 강한 경로를 적용한다. 속도는 `기본 속도 × 현재 전력 비율`. 중간 전원 연결은 전력이 약해진 지점을 보강한다.
- 레일 윗면에 닿은 동적 Rigidbody를 운반하고 CharacterController 플레이어도 레일을 탈 수 있다. 감자를 삭제하거나 끝에서 자동 수거하지 않아 물리적으로 밀리고, 쌓이거나 떨어진다. 보관함·자동 수확·로봇은 이번 범위에 없다.
- 외형은 교체 가능한 기본 메시와 색상으로 만든 임시 모델이다. 한글 안내는 프로젝트의 기존 `Fonts/MalgunGothic-Dynamic` TMP 폰트를 재사용한다.

## 확인이 필요한 임시 수치

| 항목 | 현재 값 |
| --- | --- |
| 블록 간격 | 기존 농사 그리드 간격, 기본 2m |
| 코드 총길이 / 호스 총길이 | 20m / 16m |
| 발전기 출력 / 기계당 전력 수요 | 100 / 10 |
| 레일 최고 속도 | 2m/s |
| 레일 감쇠 | 매 칸 최대 전력의 1/15 감소, 공급점에서 15칸 뒤 정지 |
| 스프링클러 범위 | 양쪽 각각 6m, 폭은 농사 그리드 1줄 |
| 스프링클러 검사 주기 | 1초 |

기계 컴포넌트의 직렬화된 필드에서 튜닝할 수 있다. 무료 건설용 기본값은 `AutomationBlock.Configure`에서 설정한다. 줄을 들고 최대 거리 밖으로 이동할 수 있지만 끝점은 최대 길이까지만 표시되고, 범위 밖 고정·연결은 거부된다.

## 검증 및 제한

`Tools > Project Potato > Validate Farm Automation`은 격리된 프리뷰 씬에서 공급 개수, 연결 종류·중복 입력, 양측 급수와 성장 연계, 통과 업그레이드, 전력 감쇠·복수 발전기 용량·중간 보강·단절, 고정점 총길이, 회수·철거를 검사한다.

Unity 플레이 모드에서 실제 Rigidbody 물체·플레이어 운반과 레일 끝 이탈을 확인했다. 프로토타입은 로컬 실행 전용으로 온라인 세션에서는 공급과 건설을 중지한다. 건설한 기계·줄은 현재 저장 데이터에 포함하지 않으므로 플레이 종료·씬 재진입 시 사라진다. 기존 농장 저장 기능에 자동화 상태를 연결하는 작업, 멀티플레이 동기화, 연료·물 소모, 건설 비용, 연구 트리 UI, 방제기는 후속 범위다.
